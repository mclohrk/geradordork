# 🕵🏿 Gerador de Dork

#googledorks #osint #cybersecurity #redteam #recon #pentest

Gerador de buscas Google Dorking organizadas por categoria. 
## O que faz

- Reúne dezenas de Google Dorks conhecidas, organizadas em categorias.
- A query real do Google visível, e dois botões: **Abrir** (nova aba já com a busca) e **Copiar** (área de transferência).
- Campo opcional de domínio alvo: preenchendo, todas as queries passam a vir prefixadas com `site:dominio`.
- Nuvem de tags com as categorias — clicar em uma abre e rola direto até ela.
  
## Categorias

- 🎻 Clássicos (robots.txt, login admin, Apache status/default page, etc)
- 🤖 IA / LLM expostos
- 📄 Documentos expostos
- 📁 Listagem de diretórios
- ⚙️ Configs de serviços
- 🗄️ Arquivos de banco de dados
- 🔑 Arquivos sensíveis
- 🌐 Subdomínios / painéis
- 📝 WordPress
- ⚠️ Potenciais vulnerabilidades


## Estrutura

## Como usar

1. Abra a página (local ou publicada).
2. (Opcional) digite um domínio alvo no campo de busca — ex: `alvo.com`.
3. Clique numa categoria pra expandir, ou use a nuvem de tags pra pular direto até ela.
4. Em cada dork: **Abrir** leva direto pro resultado no Google numa nova aba, **Copiar** joga a query pra área de transferência (pra colar onde quiser).
